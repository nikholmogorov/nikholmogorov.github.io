# haell

## Реализация и функционал

Интерактивный модуль на React с использованием Three.js и React Three Fiber для создания интерактивной 3D-сцены с эффектом параллакса, отслеживанием положения головы через веб-камеру, типизацией TypeScript и стилизацией на Tailwind.

Реализовано отслеживание перемещений головы пользователя по трём осям координат (X, Y, Z), возврат камеры в исходное положение при длительной потере лица и отладочная панель.  
  
Перемещения головы управляют положением камеры в одном из двух режимов:  
- 3D-коридор – сцена с полноценной трёхмерной геометрией  
- 2.5D Parallax with Depth Map – цветное изображение на деформированной плоскости, геометрия которой формируется на основе карты глубины[^1]  

По умолчанию настроен режим 3D-коридора.  

Для смены режима необходимо:   
1. В App.tsx заменить компонент Haell на DepthScene.  
2. Поднять значения чувствительости до 5 в constants/index.ts.

## Требования

В системе должны быть установлены [Git](https://git-scm.com), [Node.js](https://nodejs.org). Требуется веб-камера.

## Запуск проекта

1. Клонирование проекта  
```bash
npx degit https://github.com/nikholmogorov/nikholmogorov.github.io/tree/main/projects/haell haell
```

2. Установка зависимостей
```bash
cd haell
```
```bash
npm install
```

3. Запуск интерфейса
```bash
npm run dev
```

Приложение будет доступно по адресу:  
http://localhost:5173

[^1]: Карта глубины генерируется здесь:  
      [Depth Anything V2](https://huggingface.co/spaces/depth-anything/Depth-Anything-V2)

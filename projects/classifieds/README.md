# CLASSIFIEDS

## Реализация и функционал

Приложение доски объявлений с реализацией фронтенд и бекенд частей на Next.js с моковой базой данный в виде JSON-файла и интегрированной нейросетью, подсказывающей цену и описание объявления. Архитектура FSD, логика на TypeScript, управление сетевыми запросами через TanStack Query, работа с формами через React Hook Form и Zod, интерфейс из компоненетов shadcn/ui с адаптивным дизайном на Tailwind.  
  
На главной странице реализованы скелетоны карточек объявлений, динамическая отметка объявления о необходимости доработки, поиск, фильтрация, переключение сортировки в нескольких режимах, пагинация, переключение тем интерфейса (светлая-тёмная).  
На странице детальной информации реализованы скелетоны полей информации, галерея, динамическая отметка о необходимости доработки.  
На странице редактирования реализованы скелетоны инпутов информации, валидация полей при редактировании, отправка параллельных запросов к AI для подсказок цены и описания, отображение информации о результатах редактирования объявлений.  

## Требования

В системе должны быть установлены [Git](https://git-scm.com), [Node.js 20.9+](https://nodejs.org), [Ollama](https://ollama.com/).

## Запуск проекта

1. Клонирование проекта  
```bash
npx degit https://github.com/nikholmogorov/nikholmogorov.github.io/tree/main/projects/classifieds classifieds
```

2. Установка зависимостей
```bash
cd classifieds
```
```bash
npm install
```

3. Настройка AI   
```bash
ollama serve
```
```bash
ollama pull qwen2.5:1.5b
```

Для использования своей локальной модели укажите её имя в переменной `OLLAMA_PRIMARY_MODEL` в файле `.env.local`.

4. Запуск интерфейса
```bash
npm run dev
```

Приложение будет доступно по адресу:  
http://localhost:3000

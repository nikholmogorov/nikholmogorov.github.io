# Обозначение АВО

Конфигуратор обозначений аппаратов воздушного охлаждения (АВО) для Завода промышленного оборудования.

## Описание

Приложение предназначено для формирования обозначения аппарата АВО в соответствии с ГОСТ Р 51364-99 (ИСО 6758-80). Ускоряет подбор параметров и формирование обозначения, избавляя от перекрёстной сверки информации из нескольких документов.

## Функциональность

* **Динамическая блокировка параметров:** Выбор радиокнопки в одной группе автоматически ограничивает доступные варианты в других группах согласно ГОСТу.
* **Гибкий порядок заполнения:** Пользователь может начать заполнение с произвольных технических характеристик (например, рабочего давления), после чего приложение отфильтрует допустимые типы АВО и другие параметры.
* **Справочные материалы:** По требованию заказчика возле некоторых групп размещена кнопка, открывающая скриншот со справочной информацией из технической литературы.
* **Ввод пользовательских значений и сброс:**
 Предусмотрена возможность ввода собственного значения в текстовое поле, если стандартные варианты из списка не подходят.
 Ввод пробела в поле пользовательского значения сбрасывает выбор радиокнопки в текущей группе и исключает этот параметр из итоговой строки.
* **Сброс конфигурации:** Полный сброс всех выбранных значений выполняется перезагрузкой страницы.

## Особенности сборки и эксплуатации

* **Автономность:** Для использования в рабочих процессах приложение собирается в один автономный HTML-файл, объединяющий разметку, стили и JavaScript-логику с помощью плагина "vite-plugin-singlefile".
* **Локальный запуск:** Приложение запускается двойным кликом с рабочего стола сотрудника и не требует наличия веб-сервера или подключения к сети.
* **Статус:** Проект не публикуется на внешних ресурсах, за исключением портфолио разработчика.

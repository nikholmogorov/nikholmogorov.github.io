# Cube Fight

## Реализация и функционал

Демо игры на React с использованием Three.js и React Three Fiber для реализации 3D-сцены, типизацией TypeScript и стилизацией на Tailwind и NES.css.
  
Реализована заглушка для мобильных устройств, лоадер, перемещение бойцов в пределах ринга, переключение режимов камеры, возможность менять скины бойцов, соединение бойцов при контакте, совместное перемещение в пределах ринга, случайное размещение в ринге по команде "break" и звуковое сопровождение основных событий.

## Требования

В системе должны быть установлены [Git](https://git-scm.com), [Node.js](https://nodejs.org).

## Запуск проекта

1. Клонирование проекта  
```bash
npx degit https://github.com/nikholmogorov/nikholmogorov.github.io/tree/main/projects/cube-fight cube-fight
```

2. Установка зависимостей
```bash
cd cube-fight
```
```bash
npm install
```

3. Запуск интерфейса
```bash
npm run dev
```

Приложение будет доступно по адресу:  
http://localhost:5173
